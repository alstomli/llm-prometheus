# Triage Labels

Labels live in the hub tracker, `alstomli/llm-inference-server`, and use the defaults:

| Label in mattpocock/skills | Label in our tracker |
| -------------------------- | -------------------- |
| `needs-triage`             | `needs-triage`       |
| `needs-info`               | `needs-info`         |
| `ready-for-agent`          | `ready-for-agent`    |
| `ready-for-human`          | `ready-for-human`    |
| `wontfix`                  | `wontfix`            |

Every ticket also has exactly one `repo:*` label. See the hub's `docs/agents/triage-labels.md`.
